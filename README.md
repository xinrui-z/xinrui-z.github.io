# xinrui-z.github.io

Personal homepage of Xinrui Zhou: a "tree of life" drawn as a botanical plate.

- The trunk is time, from 2020 to today. Each limb is a chapter, and its leaves are what happened along it.
- Vines wind through every chapter (long-running habits); roots are what keeps me grounded.
- The Open source limb and the contribution calendar are fetched live from GitHub on each visit.

No build step. Edit `data.js` for content, `index.html` for page copy, and open `index.html` in a browser to preview.
